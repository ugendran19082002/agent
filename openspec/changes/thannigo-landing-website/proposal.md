## Why

ThanniGo has a fully-built multi-role platform (Customer, Shop Owner, Delivery Partner, Admin) but no public-facing landing page to represent it — the `website/` directory contains only a basic placeholder. A high-quality marketing landing page is needed to communicate the platform's real capabilities to users, shop partners, investors, and delivery recruits in an investor-ready, mobile-first format.

## What Changes

- Replace the existing placeholder `website/index.html` with a fully-authored, production-grade static landing page
- Add `website/style.css` — complete design system with CSS custom properties, glassmorphism, gradients, animations
- Add `website/script.js` — scroll animations, animated counters, smooth transitions, mobile navigation
- Retain and use existing `website/assets/` and `website/images/` directories for app screenshots and brand assets
- All content sourced from real, confirmed features in `frontend/` and `backend/` source code — no placeholder or hallucinated features

## Capabilities

### New Capabilities

- `landing-website`: Static multi-section marketing website for ThanniGo covering hero, about, problem statements, role-based features, how-it-works, tech stack highlights, and contact — authored from actual source code analysis

### Modified Capabilities

## Impact

- Files created/replaced: `website/index.html`, `website/style.css`, `website/script.js`
- No backend or frontend app code is affected
- No API, database, or build system changes
- SEO meta tags and OpenGraph tags added for social sharing and discoverability
